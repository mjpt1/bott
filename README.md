# سرزمین الماس‌ها - ربات آموزشی تلگرام

این پروژه یک ربات تلگرامی آموزشی، ماژولار و امن برای جامعه فارسی‌زبانان است که با پایتون و کتابخانه `python-telegram-bot` ساخته شده است.

## ویژگی‌های کلیدی

- **معماری ماژولار:** هر قابلیت اصلی در یک ماژول پایتون جداگانه قرار دارد تا توسعه و نگهداری آسان باشد.
- **پیکربندی پویا و قابل حمل:** تمام تنظیمات، از جمله توکن ربات، مسیرهای فایل و پایگاه داده، از طریق فایل `.env` قابل تنظیم هستند. این ربات بر روی هر سیستمی (سرور، VPS، یا کامپیوتر شخصی) بدون نیاز به تغییر کد قابل اجرا است.
- **امنیت:** دسترسی به پنل ادمین محدود به شناسه‌های کاربری مشخص شده در `.env` است و از دکوراتورها برای کنترل دسترسی استفاده می‌شود.
- **رابط کاربری فارسی:** تمام پیام‌ها، منوها و کامنت‌های کد به زبان فارسی هستند.
- **مدیریت کاربران:** ادمین‌ها می‌توانند کاربران جدید را تایید یا رد کنند، لیست تمام کاربران را مشاهده کرده و آن‌ها را مسدود یا آزاد کنند.

## نصب و راه‌اندازی

برای راه‌اندازی ربات، مراحل زیر را دنبال کنید:

**۱. کلون کردن پروژه:**

```bash
git clone <URL_پروژه>
cd <نام_پوشه_پروژه>
```

**۲. ساخت و فعال‌سازی محیط مجازی:**

توصیه می‌شود که از یک محیط مجازی پایتون برای ایزوله کردن وابستگی‌ها استفاده کنید.

```bash
python3 -m venv venv
source venv/bin/activate
# On Windows: venv\Scripts\activate
```

**۳. نصب وابستگی‌ها:**

تمام کتابخانه‌های مورد نیاز در فایل `requirements.txt` لیست شده‌اند.

```bash
pip install -r requirements.txt
```

**۴. پیکربندی فایل `.env`:**

یک فایل با نام `.env` در ریشه پروژه بسازید و محتوای زیر را در آن کپی کنید. سپس مقادیر را با اطلاعات خود جایگزین کنید.

```dotenv
# توکن ربات تلگرام - این توکن را از BotFather دریافت کنید
TELEGRAM_BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"

# مسیر پایگاه داده - از مسیر نسبی برای قابلیت حمل استفاده شده است
# دایرکتوری data به صورت خودکار ساخته می‌شود
DATABASE_URL="sqlite+aiosqlite:///data/bot.db"

# شناسه عددی ادمین‌های ربات - با کاما جدا شوند
# شناسه‌ی کاربری خود را می‌توانید از ربات‌هایی مانند @userinfobot دریافت کنید
ADMIN_USER_IDS="123456789,987654321"

# مسیر ذخیره‌سازی فایل‌های لاگ
LOG_FILE_PATH="logs/bot.log"

# مسیر ذخیره‌سازی فایل‌های محتوا
CONTENT_STORAGE_PATH="content"
```

## اجرای ربات

پس از تکمیل مراحل نصب و پیکربندی، می‌توانید ربات را با دستور زیر اجرا کنید:

```bash
python3 -m src.bot
```

ربات اکنون فعال است و به دستورات در تلگرام پاسخ خواهد داد. برای دسترسی به پنل مدیریت، از دستور `/admin` استفاده کنید (فقط برای ادمین‌های تعریف‌شده).
